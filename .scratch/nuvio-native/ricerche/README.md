# Ricerche della mappa `nuvio-native`

Qui vivono le note dei ticket di ricerca. Un file per ticket, stesso numero e slug:

```
ricerche/01-api-pubblica-nuvio.md
ricerche/02-collections-contratto.md
...
```

Ogni nota deve:

- partire dalla domanda del ticket, non da un riassunto generico;
- citare **fonti primarie** con URL, path/riga o nome del file;
- distinguere ciò che è **provato** da ciò che è **da testare**;
- chiudersi con “Cosa significa per YACA” e le domande che restano aperte;
- non modificare il prodotto: la ricerca non è implementazione.

Quando una nota è pronta, il ticket corrispondente passa a `Status: resolved` e la mappa aggiunge una
riga in **Decisions so far** con il gist e il link al ticket. La nota resta il posto dove vive il
dettaglio.
