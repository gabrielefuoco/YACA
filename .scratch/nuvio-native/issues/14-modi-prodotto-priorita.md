# 14 — Modi di prodotto, AI builder e priorità

## Domanda

Qual è la forma di prodotto che YACA deve prendere in Nuvio — **Lite** (0-addon), **Smart** (addon +
collection ibride), **Sync** (push account) — e in quale ordine? Dove entra l’AI Collection Builder?
Quali esperimenti decidono se la rotta è giusta, e cosa si rimanda?

## Cosa deve uscire

Una nota in `ricerche/14-modi-prodotto-priorita.md` con:

- **tre modi**:
  - **YACA Lite** — pack 0-addon, source native, community collections;
  - **YACA Smart** — collection ibride, row DNA/grafo/AI/ITA/anime;
  - **YACA Sync** — push account, home curator, profili, aggiornamenti.
  Per ognuno: valore, costo, dipendenze, rischio, metrica di successo.
- **funnel**: acquisizione → attivazione → differenziazione → retention → viralità; dove si colloca
  ogni idea.
- **AI Collection Builder**: input naturale, output collection, mapping native/addon, preview, push,
  share; costo/latenza/validazione/fallback. Dire se è un “ora” o un “dopo”.
- **MVP sequence**: 3–5 passi, con criterio di stop/go.
- **esperimenti**: i 5 test del brainstorming (pack a mano, YACA in Nuvio, poster mock, push su account
  usa-e-getta, due profili/ID) con cosa misurare.
- **decision matrix**: impatto, effort, rischio, dipendenze; cosa fare prima e cosa dopo.
- **out of scope**: conferma o sposta i confini della mappa.

## Fonti primarie

- Tutte le ricerche 01–13 (questa è la sintesi).
- Kaptain: 25k+ install dichiarati, mega collection 362 folder/1755 source.
- Xperience: 17k signup, merged rows, import catalogs, cover sets.
- Ultra MAX: companion app, poster provider.
- AIOMetadata: config import/export.
- YACA: capability reali (DNA, grafo, DuckDB, AI, ITA, anime, poster).

## Come si chiude

La nota è pronta quando:

1. i tre modi sono descritti con costi/benefici;
2. il funnel ha una metrica per fase;
3. l’AI builder ha un go/no-go motivato;
4. l’MVP è una sequenza, non una lista;
5. gli esperimenti hanno criteri di successo e stop;
6. la mappa può chiudersi: nessuna decisione operativa resta aperta.
