## FEATURE RISK

- **Prompt fact mismatch (`POST /api/preview-catalog`):** The brief stated `POST /api/preview-catalog` backs the creator's live preview. Verified code (`frontend/src/lib/api.ts:127`, `CreatorPanel.tsx:285`, `CatalogLivePreview.tsx:38`, `tests/clientDomainGuard.test.js:18`, `src/api/configurazione.js:44`) shows the frontend exclusively calls `POST /api/configurazione/anteprima` and explicitly forbids `/api/preview-catalog`. Deleting `src/api/catalog.js` carries **zero risk to the web UI**, unless an external script or unbundled client still hits `/api/preview-catalog`.
- **Legacy routes tested in unit/integration suites (`tests/`):** Removing `GET /sync-status/:userId`, `GET /api/user/:userId`, `POST /api/configure`, `GET /images/fallback`, `GET /erdb-poster/versioni`, `GET /api/trakt/health`, and `heroCatalogs` in responses will require updating/removing assertions in `tests/domainSurface.test.js`, `tests/imagesFallbackRoute.test.js`, `tests/posterVolumeContract.test.js`, `tests/traktHardening.test.js`, and `tests/configure*.test.js` (some test files import `src/api/configure/index.js` directly).
- **External/cron callers:** `GET /api/cron/warmup` (`index.js:150`) and `GET /api/admin/*` (`src/api/admin.js`) are intentionally kept because external monitors (Uptime Robot) and ops tooling may call them outside the repo.
- **Cached Stremio libraries (`GET /images/poster/...`):** Keep the 302 trampoline in `src/api/stremio.js:367-384` because `libraryPosterRefresh.js` shows existing Stremio libraries can hold legacy `/images/poster/...` URLs.
- **Schema/migration compatibility:** Dropping `UserLibraryOrder` dual-writes and `ProfileUiState` assumes no rollback to a version reading those transitional collections; `AddonConfig.profiles[].raw_ui_state` remains the live read/write path used by `UserConfig.js` and `frontend/src/lib/utils.ts`.
- **Response shape changes on `/api/profilo` & `/api/configurazione/anteprima`:** Dropping `heroCatalogs` and `diagnosi` is safe for the current Next.js export (`frontend/src/` never reads them), but `tests/domainSurface.test.js:293,345-348,366` and `tests/shelfLivePreview.test.js:326-344` currently assert those fields exist.

**Estimated net code reduction:** ~1,150–1,300 lines across `src/api/**`, `index.js`, `src/profile/**`, `src/library/**`, and `src/models/**`.
