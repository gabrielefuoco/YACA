## FEATURE RISK

1. **Removing `TraktProvider` (`trakt_*`)**: Zero impact on current presets/manifest, **but** if any legacy user `AddonConfig` in MongoDB still has `trakt_watchlist_*` / `trakt_popular_shows` / `trakt_favorites_*` in `profile.catalogs` or `customCatalogs`, those Stremio rows would start returning `[]`.
2. **Changing `urlPosterInCache` in `StremioFormatter.js`**: Dropping `urlPosterInCache` (instead of replacing `fs.statSync` with an in-memory dir index) would cause Stremio to receive TMDB poster URLs instead of pre-rendered `/erdb-poster/*` URLs on badgeless cached titles, and on `/meta` detail responses would drop the `_ITA` cached poster swap. Keep the behavior using an in-memory cache/readdir set.
3. **Altering `tier2Enrich` (`append_to_response` / `ENRICH_BUDGET_MS`)**: Lowering `ENRICH_BUDGET_MS` or trimming `getTmdbMetaDetails` calls reduces search latency, **but** on cold cache it can surface raw Tier 2 English titles without posters/Italian titles on the first search (`_tier2` items), and dropping `images`/`genres` in `tier2Enrich` would omit logo/genres on enriched search cards.
4. **Slicing `simili` IDs to 20 before DuckDB filters**: If `kidsMode` or `typeSelectors.anime` (`only`/`exclude`) is active and filters out items from the top 20 graph neighbors, slicing to 20 pre-filter would return a short page (<20) in Stremio. Always over-fetch (`skip + cap * 2`) when filters are active, with fallback widening on shortfall.
5. **Removing legacy `yaca_preset_` stripping or `/images/fallback` or `types: ['other']`**: Stremio clients or `profileProcessor.js` with existing installs may still request `yaca_preset_*` IDs or cached `/images/fallback` poster URLs; changing `manifest.types` requires bumping `VERSIONE_MANIFEST`. (Note: `/images/poster/*` in `api/stremio.js` MUST stay for cached Stremio libraries.)
6. **Dropping `seenIds` dedupe in `catalogHandler` unconditionally**: Multi-page `hasPostFetchFilter` loops (`while` over `skip`) and multi-query `AiDiscoveryProvider` / consensus paths can emit duplicates across batches; only skip `seenIds` on single-page unique-ID paths.

## SUMMARY

- **Cuts in `src/stremio/**` & `src/catalog/**` (items 12–20, excluding `ricerca/registry.js` & `duckDbProvider.js`):** ~530 lines removable (`~715` lines including coupled `src/ricerca/registry.js` + `src/indice/duckDbProvider.js` duplication).
- **Top speed wins:** (1) memoizing `getPresets()` + pre-hashing `canonicalCatalogDefinition`, (2) removing `rateLimitedMap` 900 ms artificial sleep + batching `idratazione.js` DuckDB lookups, (3) slicing `simili` before `SELECT *` + slim DuckDB catalog projection + skipping duplicate `sanitizeCatalogMeta` / `fs.statSync` + dropping duplicate `profiloDi` Mongo query.
