# Archivio degli esperimenti `graph_dense`

I moduli spostati qui sono trainer, teacher, valutatori e prototipi storici. Restano importabili tramite
il namespace compatibile `services.graph_dense` per poter riprodurre gli esperimenti; non sono usati
né dalla pipeline V45 né dal servizio YACA.

Il builder V45 canonico è `services/graph/build/` e si lancia con `PYTHONPATH=services py -m graph.build`.
